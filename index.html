Генератор QR-коду для оплати за IBAN

Як це працює

Введіть IBAN, код ЄДРПОУ або РНОКПП, отримувача, суму та призначення платежу — QR-код з'явиться автоматично. Платник сканує його камерою або застосунком свого банку, і всі реквізити підставляються у платіж без ручного введення.

Код формується за стандартом Національного банку України для кредитових переказів (формат 002) з обов'язковим знаком ₴ у центрі. Підходить для рахунків на оплату, комунальних платежів, збору донатів та оплати послуг ФОП.

Усі дані обробляються лише у вашому браузері й нікуди не надсилаються. Посиланням на сторінку із заповненими полями можна поділитися — реквізити зберігаються в адресі.

Версія формату 002 — Постанова НБУ № 97 від 19.08.2025 · GitHub

Ця сторінка не пов'язана з жодним банком, Національним банком України чи платіжною системою і не здійснює переказів — вона лише формує QR-код за відкритим стандартом.
